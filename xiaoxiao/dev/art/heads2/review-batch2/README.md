# 第2批素材检查

本批新增80张：37张棋盘脸、43张性格脸。动物乐园和蛋蛋农场的45个常规角色现在都有两张脸；小美人鱼、金蛋母鸡两位隐藏款归第4批。当前源素材累计92/219张，后续批次还需127张。

## 文件与几何检查

| 项目 | 结果 |
| --- | --- |
| 新增文件清单 | 80张齐全，id与HEADS.md一致 |
| PNG尺寸与颜色模式 | 92张均为1024×1024 RGBA |
| 透明背景与留白 | 四角透明，轮廓均在940方框内；最小留白56像素 |
| 半透明边缘 | 最宽3像素 |
| 表情轮廓对齐 | 45对棋盘脸/性格脸的alpha通道逐像素一致 |
| 已认可的第1批 | 原12张文件内容未改动 |

表情从对应棋盘脸编辑生成，再按棋盘脸配准并保留其透明轮廓。细小手、道具和水花收在头像轮廓内。像转头、奔跑、伸脖子的性格动作，以头部神态和靠近脸的小道具表达，保持头像交付形式。

同色组棋盘脸两两比较剪影，结果见[silhouette-metrics.json](silhouette-metrics.json)。海豚改成长吻与弧形背鳍；小黄鸭去掉头顶翘毛、加宽扁嘴。海豚/鲨鱼剪影重合度约60%，小黄鸭/小黄鸡约83%；本批同色组最高重合度低于90%。重合度用于定位相似轮廓，实际辨识效果仍需本批进游戏检查。

## 主色与边缘

按主色家族宽容区间估算可见面积，当前92张均达到60%。估算包含明暗变化，方法和数值见[colour-metrics.json](colour-metrics.json)；这是色系筛查，不是逐像素人工材质标注。小鲨鱼、毛驴、暹罗猫及部分性格脸已收紧次要色块。黑白组棋盘脸的深色中性区域估算均小于一半。

导出时清理了微弱杂点和透明毛边，保留头像内部的毡布纹理。几何检测原始数据见[metrics.json](metrics.json)，汇总见[validation.json](validation.json)。
