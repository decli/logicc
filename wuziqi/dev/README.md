# 五子棋 · 开发

```bash
python3 wuziqi/dev/build.py              # src/* → ../index.html（一个文件，无依赖）
node wuziqi/dev/test.js 20               # 电脑对手互相下：每步合法、强的赢弱的、猫头鹰想多久，再加几个必须走对的局面
python3 dev/voice/build.py wuziqi        # 改了台词后重录语音包 ../voice.bin|json（只录新句子）
```

地址后面加 `?debug` 会在控制台留一个 `WZ`（`WZ.UI.start({ opp: WZ.OPPS[3] })` 直接和猫头鹰下，`WZ.Gomoku.hint(WZ.UI.pos)` 看它会建议下哪）。

| 文件 | 做什么 |
| --- | --- |
| `src/head.html` | 页面骨架和全部样式（木头棋盘、奶油色卡片、叶绿色按钮，和动物消消乐的怪趣森林一个调子） |
| `src/core.js` | 小工具和 `Store`（存在 `logicc.wuziqi.v1`：和每个对手的输赢、两人对战的比分、谁先下、提醒开关、声音） |
| `src/engine.js` | 规则和四个电脑对手，不碰页面（`test.js` 在 node 里跑它）。自由规则：五个或更多连成一线就赢，黑棋先下，不设禁手。所有判断都看「五元组」：棋盘上每一段连续五格，只有一种颜色的子才有用，子越多越值钱；下一步的好坏（`score`）用经典的五元组打分表，局面的好坏（`value`）是双方五元组的总和，落子、提子时增量更新 |
| `src/lines.js` | `OPPS`（四个对手：小黄鸡、小兔子在 11×11 上，小狐狸、猫头鹰在 15×15 上）和旁白的每一句话；`voice/collect.js` 从这里列出要录的句子 |
| `src/board.js` | 画布上的棋盘：木纹和线（每换一次大小画一次）、棋子、最后一步的小红点、手指下的半透明棋子（抬手的地方才落子，可以滑着调）、提醒的红圈橙圈、💡 的光、连成五个的金线；还有赢了撒的彩纸 |
| `src/ui.js` | 选对手的首页、一局棋（电脑的回合、提醒、支一招、悔棋）、结束的卡片 |
| `src/audio.js` `src/voice.js` | Web Audio 现做的落子声和提示音；预先录好的旁白（`../voice.bin|json`，晓晓，和思维小画本其他游戏一样） |

## 四个电脑对手

| 对手 | 棋盘 | 怎么下 |
| --- | --- | --- |
| 小黄鸡 | 11×11 | 在看起来不错的八个点里随便挑，自己能连五也有三成会看漏，你快连五了它一半以上不堵 |
| 小兔子 | 11×11 | 在最好的三个点里挑，能连五一定连，你快连五了九成会堵 |
| 小狐狸 | 15×15 | 每步都下打分最高的点（进攻和防守算在一起），该堵一定堵 |
| 猫头鹰 | 15×15 | 先找「连续冲四」能不能直接赢（VCF），再往后算几步（alpha-beta，2 → 4 → 6 层，最多想 0.9 秒），选好的那步还要确认对方没有连续冲四能赢 |

`node wuziqi/dev/test.js 20` 的结果（各 20 局，轮流先手）：小兔子对小黄鸡 19 胜 1 负，小狐狸对小兔子 18 胜 2 负，猫头鹰对小狐狸 20 胜 0 负；猫头鹰一步一般想 0.1 秒左右，最长不到 0.6 秒。

## 给孩子的设计

- **提醒**（默认开，侧栏 🔔 可关）：对方下一步就能连成五个，那个点亮红圈，旁白「小心！它马上就要连成五个了，快堵住！」；对方再下一步就能有两种连五的办法（活三的两头、跳三的空当），亮橙色虚线圈，「注意！它连成三个了，两头都空着，快堵住一头！」。同一个威胁只说一次；堵住了夸一句「堵得好！」
- **支一招**：棋盘上亮出一个好点（小狐狸的选择，能连续冲四就给冲四），不扣分
- **悔棋**：和电脑下时退回两步（电脑那步和自己那步），输了也能「退回去看看」；两个人下时退一步
- **先下后下**：和电脑下默认孩子执黑先下，也可以让电脑先下、自己执白
- 对手是动物消消乐里怪趣森林的四个小伙伴（`img/` 是从 `xiaoxiao/big/` 缩小的），难度用星星表示；还没赢够两局的最容易的那个标着「去挑战」
