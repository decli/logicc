# 思维小画本（logicc）

给幼儿园大班小朋友的思维训练小游戏，把纸质练习册上的题目改成了平板上能玩的游戏。
闯关游戏和教小学一到四年级 64 首古诗词的「古诗小剧场」都在一个 HTML 文件里，零依赖、可离线，加到主屏幕就是一个 App；另有一个会说话的小世界「造物」放在 `zaowu/`，一架可以弹的 3D 三角钢琴「彩虹钢琴」放在 `piano/`，开心消消乐那样的十关闯关「动物消消乐」放在 `xiaoxiao/`，练三维空间感的 3D 小世界「魔方世界」放在 `mofang/`。

在线玩：<https://decli.github.io/logicc>

每个游戏进去先选难度，关卡是有设计意图的递进，不是单纯把格子变多。

| 游戏 | 原型 | 练什么 | 关卡怎么加难 |
| --- | --- | --- | --- |
| 找数字 | 舒尔特方格 | 视觉搜索、专注力、抑制控制 | 3×3 → 5×5 → 倒序找 → 红蓝两条线索交替 |
| 数点点 | 多米诺点数 | 目测点数、凑十、瞬时记忆 | 凑 5 → 凑 10 → 比多少 → 闪一秒后回忆 → 三张凑总数 |
| 凑数字 | 10 以内分解与组成 | 数的组成、逆向思维 | 缺右边 → 缺左边 → 求总数 → 分成三份 |
| 古诗小剧场 | 看图讲故事 + 跟读 | 背古诗：一到四年级 64 首 | 每首四步：看故事 → 跟我念 → 接下句 → 我来背；背会了打庆功鼓 |
| 照镜子 | 空间变换 | 先认（哪个是镜子里的）→ 自己动（移动自己看镜中反向移动）→ 带影子放 → 自己放 → 上下 → 对角线 → 旋转；每次完成播「对折合上」动画 |
| 魔方世界 | 立方体视角题、索玛方块、魔方、乐高 | 三维空间感：换视角、心理旋转、展开与折叠、照样子搭建 | 六个小岛三十一关：从前面 → 左右 → 上面看积木 → 反过来认是谁看的；数积木（藏起来的也算）；转积木钻墙洞；补纸盒展开图；二阶 → 三阶魔方；照样子搭积木，最后只看两张视图来搭 |
| 动物消消乐 | 开心消消乐 | 观察、预判下落、先想后动；每局之后一页加减法 | 十关，每关多一样新东西：收集 → 冰块 → 礼物盒 → 小企鹅 → 泡泡 → 双层冰 → 礼物城墙 → 六种动物 → 泡泡冰宫 → 爱心大挑战 |
| 彩虹钢琴 | — | 音乐启蒙：音高、唱名、节奏、听音模唱 | 不分关：自己弹 / 跟着亮灯学 13 首儿歌 / 听钢琴自己演奏 / 学小鸟唱 2→5 个音 |
| 找规律 | 行测（公务员考试）图形推理 | 归纳推理、图形规律 | 数量 → 遍历（九宫格）→ 平移 → 旋转 → 叠加 → 线数 → 去同存异 → 两条规律一起；每题都能点 💡 听讲解 |

## 给孩子的设计取舍

- **进去先选难度**，五到六档，每档写清楚练的是什么；也可以交给自动调节
- **一组三关**，1–2 分钟一轮，顶部三个圆点让孩子看得见"快结束了"；三关给一张贴纸。
- **不判错**：点错只是轻轻抖一下，没有红叉、不扣分、没有倒计时，可以一直试。
- **全程语音**：不识字也能玩。每题自动朗读，右上角 🔊 可随时重读一遍。读题的声音提前用微软神经网络语音录好（见下文「语音」），语速放慢到孩子听得清，多音字逐个核对过。
- **自适应难度**：连续三关零失误自动升级，一关错四次自动降级；家长可在 ⚙️ 里锁定并手动调。
- **卡住会提示**：7–20 秒没动作，正确选项自动发光并重读题目；照镜子可以"看一眼"。
- **声音**：Web Audio 实时合成的背景音乐与音效，无音频文件；朗读时音乐自动压低。
- **慢慢来模式**（默认开）：题目分批淡入而不是一次铺满；找数字这类关卡拆成「先找 5 个」的小目标，其余先蒙起来，一段一段揭开
- **题目每局现生成**：找规律的图形、走法、选项都随机，实测每关 10~12 局零重复；魔方世界的积木堆、墙洞、纸盒展开图、魔方打乱也每局现出
- **按容器排版**：所有尺寸由实际可用区域测量得出，不用视口单位，分屏、缩放、PWA 全屏下都不会溢出或留空。

## 十二个游戏：七个闯关游戏共 46 关，外加「古诗小剧场」「动物消消乐」「魔方世界」和自由玩的「造物」「彩虹钢琴」

体系按执行功能三件套（工作记忆 / 抑制控制 / 认知灵活性，Miyake & Diamond）
加上早期数学与空间能力来铺，六个来自孩子原本的纸质练习册，六个是补进来的。

| 游戏 | 主要练什么 | 关卡怎么加难 |
| --- | --- | --- |
| 找数字 | 视觉搜索、抑制 | 3×3 → 5×5 → 倒序 → 红蓝两条线索交替 |
| 数点点 | 目测点数、凑十、瞬时记忆 | 凑 5 → 凑 10 → 比多少 → 闪一秒回忆 → 三张凑总数 |
| 凑数字 | 数的组成、逆向 | 缺右边 → 缺左边 → 求总数 → 分成三份 |
| 古诗小剧场 | **背古诗**：听懂、念出声、背下来 | 64 首诗各四步：看故事（小故事 + 每句大白话）→ 跟我念 → 接下句 → 我来背，后三步各一颗星；小话筒听她有没有念出声 |
| 照镜子 | 空间变换 | 先认（哪个是镜子里的）→ 自己动（移动自己看镜中反向移动）→ 带影子放 → 自己放 → 上下 → 对角线 → 旋转；每次完成播「对折合上」动画 |
| 魔方世界 | **三维空间感：换视角、心理旋转、展开折叠、照样子搭建** | 六个 3D 小岛三十一关（见下面「魔方世界」），外加自由玩魔方和自由搭城堡 |
| 动物消消乐 | 观察配对、预判下落、计划；加减法口算 | 十关三消闯关（见下面「动物消消乐」），每玩一局，再玩或进下一关前先做对一页 20 道加减法 |
| 找规律 | **归纳推理：行测图形推理** | 数一数 → 每行都有 → 走一走 → 转一转 → 叠一叠 → 数线条 → 一样的消掉 → 两个一起变，再加三个挑战关：穿过几次 → 一层套一层 → 框里框外（见下面「找规律」） |
| 方块拼拼 | **空间构建、心理旋转、动态判断** | 前四关静态：补缺口 → 先在脑子里转好再选 → 两块拼满 → 三块拼满；后三关真落体，一关加一条难度轴：会消行（6×16）→ 先挖开垫底石块（7×18）→ 越消越快（8×20），每关三局的目标行数再逐局加码，配 🔄 ◀ ▼ ▶ 手柄和 ↩︎ 退回、调速（0.7~1.3）、⏸ 暂停，带得分与每关最高分，也支持键盘 |
| 造物 | **想象与创造、中英双语词汇与日常句子、听觉序列记忆、绘画表达** | 不分关：敲开混沌之蛋 → 种树、召云、画圈造出会说话的小生灵；认一认 / 找一找 / 说一说 / 画一画四个小游戏；「跟我唱」从 2 个音加到 5 个音；25 张发现贴纸 + 29 个词的词语本 |
| 彩虹钢琴 | **音乐启蒙：音高与唱名、节奏、听音模唱** | 不分关：自己弹；「跟我弹」13 首儿歌按难度 1–3 星，跟着发光的键一个音一个音弹，钢琴自动配和弦；「听我弹」看钢琴自己演奏 16 首；「学小鸟」听 2 个音学唱，逐步加到 5 个 |
| 记住亮过的 | **空间工作记忆** | Corsi 方块跨度 2 → 4，最后一关要倒着点 |

设计依据几条实测结论：
- 单纯玩会掉落的俄罗斯方块，对心理旋转的迁移在高效力重复实验中做不出来
  （Mayer 综述；Timm 等人 2024，与玩单人纸牌无差异）；但结构化积木拼搭在 fMRI
  研究中确实改善了心理旋转成绩与相关脑区激活。关键差别是必须「先在脑子里转好再动手」。
  所以方块拼拼把两者都保留：前四关静态拼合、不给旋转按钮，逼着先想；后三关才是真落体，
  练的是另一回事——时间压力下的动态空间判断，速度作为难度参数
- 落体关：堆满时给正经的结束面板（再来一局 / 调慢再来 / 回家），而不是无限自动救援——
  游戏得有明确的一局；落定后有 260 毫秒冷却，防止连点把下一块也直接摔到底
- 随时可以 ↩︎ 退回上一步落子（最多回退 15 步），放错了不必推倒重来；拼满关也一样，剩下的块一块都放不进去时，伙伴栏会提示「点退回一步」，按钮跟着闪
- 落体关的按钮按用途分两区（第一版七个键排成一整行、两端顶到屏幕两侧，孩子反馈「太分散」）：
  玩的四个键收成倒 T 形手柄贴在棋盘右侧下半截，◀ ▼ ▶ 就是方块要去的方向，上面一格是 🔄；
  退回 / 调速 / 暂停挪进右侧伙伴栏，跟「再读一遍 / 回家」一列，离手柄远、不会误触。
  按钮约 20mm、外扩一圈不可见热区、键与键留 20px 以上空隙；省下的高度全给棋盘，竖着拿时手柄挪到棋盘正下方
- 落体关的难度分两层递进（第一版消 2~4 行就过，大孩子一会儿就腻了）：
  关与关之间各加一条新的难度轴——第 5 关只学消行；第 6 关底下先垫几行带缺口的石块，得先补缺口往下挖，棋盘也矮了一截；
  第 7 关再加自动加速，每消 3 行快一档（不改孩子自己选的速度，下一局从头算，退回一步也会把速度退回去）。
  每关里的三局再逐局加码：要消的行数 3/4/5 → 4/5/6 → 6/8/10，垫底石块 2/3/4 行。每局开头提示这一局消几行、垫了几行
- 速度 0.7 ~ 1.3 七档，默认 1.0（每 0.95 秒落一格，即旧版的「快」——棋盘加高后旧的「中」太磨蹭）。
  点伙伴栏的「速度」弹出七个大按钮，选完记住；弹出时游戏自动停住，免得方块趁机落下去
- 落体关有得分，给一直玩下去的理由：落定一块 10 分；一次消 1 / 2 / 3 / 4 行得 100 / 300 / 600 / 1000，
  连着几块都消行再加连消奖励；总分乘以当前速度，敢调快分就高。每关记最高分，
  「下一个」下面的得分牌实时显示，超过纪录时牌子变黄、放礼花；退回一步连分数一起退
- 消行有独立特效：整行逐格爆闪、拉伸消散，并从行中心迸出星光和「+分数」；
  消行时其余方块只微微变淡，看得清哪几行被消掉、剩下的落到了哪里
- 消够行数过关时，剩下的方块留在棋盘上，上面盖一层「🎉 过关！这一局 N 分」，再进下一局——
  不再一下子换成空棋盘，免得看起来像「消了三行，整个棋盘都清空了」；
  过关的表扬也等「一次消掉 N 行」念完再说，不会把它打断
- 古诗小剧场（原来叫古诗太鼓）替换了原来的「找一样」：逐位比对在找数字、水果连连看里已有练习，背古诗是孩子马上要面对、又最怕「正儿八经学」的一块。
  第一版做成了「古诗花园」（一首诗一朵花，每一步三个练习式小游戏，前一首长叶后一首才解锁），家长试完的反馈是：规则看不懂、没有游戏感、没有玩下去的动力。
  所以推倒重来，做成音乐节奏游戏，背诗藏在「想拿满星」里
- 彩虹钢琴替换了原来的「走迷宫」：路径规划在连点成画、水果连连看里已有练习，而音乐是体系里缺的一块
- 魔方世界替换了原来的「连点成画」：数序在找数字里已有练习，而真正的三维空间（换个方向看、在脑子里转、把纸折成盒子）是体系里缺的一块，平面的照镜子、方块拼拼练不到
- 动物消消乐替换了原来的「水果连连看」：孩子玩过觉得连连看没意思，想玩开心消消乐那样互动更强、能闯关的；视觉搜索在找数字里仍有练习。
  消消乐很容易玩上瘾，所以它自带「防沉迷 + 玩中学」：每玩一局，想再玩或进下一关，都要先做对一页数学题
- 造物替换了原来的「小鱼朝哪边」。它是唯一没有对错的一格：孩子画什么都会活过来，
  想让它做什么点一下就行，用来放松和表达；里面的「跟我唱」仍是有梯度的记忆练习
- 找规律第一版是 AB / ABC 循环（难度按 Rittle-Johnson 等人对 4 岁儿童的实测排序），孩子玩熟了、嫌简单，
  换成了公务员考试「行测」里的图形推理（见下面「找规律」）
- 学龄前工作记忆容量实测约 3.2 个条目，Corsi 跨度因此定在 2~4
- 认知灵活性是三件套里最晚成熟的一块，DCCS 前测平均仅 6.9/12，所以「中途换规则」
  单独占一关，并给足语音与提示

## 大屏横屏改版（当前版本）

- 游戏中取消顶栏，棋盘吃满屏高，右侧固定伙伴栏放题干、进度、计时和按钮
- 选难度改成高度递增的台阶，每级嵌这一关真实棋盘的缩略图
- 所有尺寸走统一的等比缩放，按容器实测，分屏 / 缩放 / 竖屏都不溢出
- 每组三关计时，记录每关最快用时，通关时给出「比上次快几秒」
- 关卡、星星、贴纸、最快用时存 localStorage（可在家长设置里关掉）
- 顶栏 📖 进贴纸册，看 16 张收集进度
- **自动发光提示默认关闭**：原来十几秒没动作就点亮正确答案，等于替孩子做完了视觉搜索；
  现在默认只重读题目，发光提示降级为家长设置里的开关
- 人工提示明码标价：照镜子的「看一眼」少一颗星；凑数字的「摆点点」不扣星（不泄题）
- 照镜子每轮随机换填充形状与配色，不再是一片方块

## 家长设置（右上角 ⚙️）

音效 / 语音读题 / 背景音乐 / 自动调整难度开关，以及每个游戏的关卡手动加减。

## 找规律（行测图形推理）

第一版是 AB / ABC 循环补空，孩子玩熟了、嫌太简单。现在换成公务员考试「行测」里的图形推理：照着常考的题型**原创出题**（不照搬真题），题目每局现生成。
形式也照行测：一排图或一个九宫格，问「问号里该放哪一个」，下面四个选项 A B C D。

| 关 | 行测题型 | 题目长什么样 | 难在哪 |
| --- | --- | --- | --- |
| 1 数一数 | 数量 | 一排格子，每格里的星星 / 圆点每次多一个、多两个或少一个 | 两种形状混在一起时要数总数，什么形状都算 |
| 2 每行都有 | 遍历 | 九宫格，每一行、每一列三种形状各有一个 | 一半的题颜色也各有一个（形状、颜色两张表正交，颜色没法跟着形状猜） |
| 3 走一走 | 平移 | 3×3 的格子，黑格子沿着外圈走 | 顺时针还是逆时针，一次走一格还是两格 |
| 4 转一转 | 旋转 | 圆盘上八个点，箭头每次转几格 | 同上；转两格时四步正好转一圈，答案和第一个图一样 |
| 5 叠一叠 | 叠加 | 九宫格，每一行前两个图叠起来就是第三个 | 要先从前两行看出规律，再用到第三行 |
| 6 数线条 | 线数 | 每个图由折线、多边形拼成，直线数每次多一条（或都一样多） | 折线拐一下就是新的一条 |
| 7 一样的消掉 | 去同存异 | 九宫格，叠在一起时两个都黑的格子消掉 | 干扰项里有「直接叠」和「只留一样的」 |
| 8 两个一起变 | 双规律 | 黑球、白球在外圈各走各的 | 两条规律要同时盯住，干扰项只对一半 |
| 9 穿过几次 | 交点数（挑战） | 一条弯弯的线和一条横线，穿过几次每次多一次、少一次或一样多 | 有的弯拐回来没碰到横线，不算；线一密就容易数漏 |
| 10 一层套一层 | 位置遍历（挑战） | 九宫格，每个图是三层套在一起；每一行里，最外面、中间、最里面三层，三样东西各轮一次 | 三行用的东西不一样（两套形状、一套颜色），不能整个图去别的行里找，得一层一层看 |
| 11 框里框外 | 位置 + 里外（挑战） | 小圆圈沿着方框的四个角、四条边走，同时一次在框里、一次在框外 | 两条规律一起；干扰项有「位置对、里外错」和「里外对、位置差一步」 |

后三关是看了行测真题之后加的挑战关：真题大多一道题藏两条规律、要看的地方又很细，六岁孩子自己做基本做不出来，所以只挑了讲一讲就能懂的三类（交点数、套娃式的位置遍历、位置加里外），图画大、一次只多一样难点。展开图折盒子、平移拼图这类要在脑子里折叠、拼合的空间题没有做。

- **💡 讲一讲**：每题右边都有。点了以后一步一句话讲，画面跟着演：数到哪个标到哪个号、在格子下面挂上数字；
  箭头画出黑格子、小圆圈走过的路、圆盘上画出转过的弧；套在一起的图一层一层描绿；前两个图（一个涂蓝、一个涂橙）飞到第三格叠起来，一样的格子闪几下消掉；最后问号里出现答案的影子，正确的选项亮起来
- **讲解在答对之前点要少一颗星**（等于看了答案，和照镜子的「看一眼」一样明码标价），答对之后点不扣
- **试错碰对的题停一下**：点错过再答对时不自动跳下一题，右边出现「💡 为什么是它」和「下一题 ▶」，给她听为什么的机会；一次就答对的照常自动往下走
- 点错两次，小灯泡会闪，提示「不会也没关系，点小灯泡，听我讲一讲」
- 讲解的每一句都由固定的几种说法拼成（比如「它每次沿着外圈，顺时针走两格」），全部列在 `index.html` 的 `GL_T`，提前录好放进自己的语音包 `voice-gl`（约 180 句、2.7 MB），不和首页读题的 `voice-zh` 混在一起。
  `dev/voice/collect_gl.js` 列句子时会把每类题各出 3000 道，查有没有讲解说了却没录的句子、四个选项是不是都不一样
- 旧版的关卡进度和最快用时对不上新题，第一次打开新版时找规律从第 1 关重新开始

### 加一类题

在 `index.html` 的 `/* ==GL-DATA== */` 一段里写一个出题函数（返回题目的图、四个选项、答案，和讲解的每一步说什么、画面做什么），挂进 `GL_GEN`，
讲解里新的说法加进 `GL_T` 和 `glLines()`；再在 `GAMES` 的找规律里加一关。然后运行 `python3 dev/voice/build.py gl` 重录语音包（只录新句子）。

## 古诗小剧场

统编版小学语文一到四年级要背的古诗词（课文和「日积月累」里的，都是几句话的短诗、短词）一共 64 首，按年级分页，每页先上册后下册。

### 为什么不打鼓了

第一版叫「古诗太鼓」：朗诵响起来，诗句变成灯笼滑向小鼓，孩子拍鼓。看孩子实际玩下来，问题很明显：
灯笼在动、鼓在响，注意力全在拍鼓上，她以为这就是个打鼓游戏；「藏尾巴」那关她只拍不念，根本不知道要念出来。
这和研究说的一致：
- **出声念才记得住**（production effect）：五岁孩子看图念出来的词，比只看、或者看着听，记得更牢
- **有趣但跟内容无关的东西会拖累学习**（seductive details，58 项研究的元分析）：滑动的灯笼、连击、分数正是这种东西

所以学诗的路上不再打鼓。核心变成：**听懂 → 念出声 → 背下来**，而且每一步都让她清清楚楚知道「现在轮到谁」。

### 四步

| 步骤 | 做什么 | 怎么知道轮到她 |
|---|---|---|
| 👀 看故事 | 先讲一段这首诗的小故事（谁写的、在哪儿、看到了什么）；然后念一句、画面演一句，旁白再用大白话讲这句的意思 | 只听，不用做 |
| 🗣️ 跟我念 | 我念一句（字变红），她跟着念一句 | 底下一条变绿，大话筒跳动，写着「轮到你！大声念」，第一次还会说出来；她一出声，话筒的光圈和音量条跟着动，诗句一个字一个字变**绿**；念完画面才动起来——画是她念出来的 |
| 🧩 接下句 | 我念前面，每句最后一拍藏成方框，她接上；接完我再念一遍后半句给她对 | 同上 |
| 🏆 我来背 | 每句只露第一个字，她背一句、翻开一句 | 同上；没听见她念，就说「没关系，我先念」，带她念一遍 |

- **画面是奖励**：后三步里，这一句的动画要等她念完才演
- **话筒只听「开没开口、念了多长」**，不判对错（五岁孩子的语音识别不可靠，判错了更伤积极性）。7 秒没开口会提醒她大声一点再念一遍，第二次还没听见就带着她念，不卡住
- **用不了话筒**（家长设置里关掉、没给权限、旧设备）就换成「✋ 我念完了」大按钮，念完自己点
- **星星**：跟我念、接下句、我来背各一颗，每首最多 3 颗；用话筒时要听见她念了六成以上的句子才给
- **听自己背的**：「我来背」整段录下来，背完马上放给她听；诗卡上有「🎧 听我背的」，家长随时能听。录音只存在这台设备的浏览器里（IndexedDB），每首留最新一次，「清空」会一起清掉
- **庆功鼓**：「我来背」拿到星之后，诗卡上出现「🥁 庆功鼓」，原来的打鼓玩法留在这里当奖励

### 画面和诗句

- **一屏三块，谁也不挡谁**：最下面一条是「轮到谁」（打庆功鼓时是鼓道）；上面一块是整首诗（拼音 + 楷体），一块是这首诗的画。宽屏诗在左、画在右，竖屏诗在上、画在下；
  画框和画一样的宽高比，整幅画都看得见。诗按格子大小自动定一行放一句还是两句，取字更大的那种（《江南》七句在宽屏上排成两列）
- **红字是我念，绿字是她念**：朗诵念到哪个字哪个字变红；她念的时候字跟着她的声音一个个变绿
- **画是这首诗的诗画**：念到哪句演哪句（大白鹅探出头、仰头唱歌、水变绿、红掌划水……）。64 幅画全部是代码画的 SVG + emoji
- **没有锁**：随便挑；选诗页上每首诗显示拿了几颗星，年级标签上是这个年级一共拿了几颗。诗卡上下一步该做的那一步是黄色的

### 朗诵

- 晓晓（首页读题的那个声音）。原来家长设置里还能换成云希（男声），诗多了以后去掉了：语音包少一半，而且云希的句尾常常压成气声，量不出声调
- 一首诗**一口气录完**，声音的起伏是连着的（逗号处扬着、句号处落下），再在句与句之间的停顿处切开，按手定的停顿重新接上：逗号后 0.55 秒、句号后 0.9 秒，标题和作者后各停一下。句内大约每秒 3 个字
- **按诵读节奏念**：五言「二三」、七言「四三」中间换一小口气（鱼戏，莲叶间；泉眼无声，惜细流），停顿收紧到约 0.2 秒。这样念，句尾的字声调才站得住
- 标题、作者、每一句里每个字从第几秒开始也算好了（汉语音节之间有响度的小低谷）：一句一句截出来放、朗诵时字一个个变红、庆功鼓的鼓谱都靠它
- 多音字按教材注音：先定每个字该读什么（咏鹅「曲项」qū、春晓「处处」chù、鹿柴 zhài、返景 yǐng、雪梅「未肯降」xiáng、塞下曲「单于」chán yú……），再逐个检查语音服务实际读成了什么，读错的换成只有这个读音的常用同音字送去合成（屏幕上照旧显示原字）。
  拿不准的不再一律替换：《江南》「鱼戏莲叶间」原来为保险把「间」换成「坚」送去合成，「莲叶坚」不成话，语音反而把句尾压成了轻声（家长听出来「间」怪怪的）。现在两种都录，哪种声调对用哪种
- **每句最后一个字的声调逐句量**（句尾最容易被句子语气压坏）：拿这个字的音高跟同一句其他字比——一声要比中间高、二声要往上扬、四声要从高处落下。一首诗录四遍（带不带诵读停顿 × 拿不准的多音字换不换），每句挑声调对的那一遍；都不对，就单独再录这一句（换句末标点、换同音字）；还不对，用 Praat 的 PSOLA 只改这一个字的音高曲线（时长和音色不动）。每首诗每句用了哪一遍、分数多少记在 `dev/voice/tones-voice-shi*.json`
- 《咏鹅》「鹅，鹅，鹅，」单独成句时句末降调把二声压成了 è，合成时写成「鹅？鹅？鹅？」，三个鹅的音高都上扬 4 个半音

### 加一首诗

在 `index.html` 的 `POEMS` 里照样写一条：每句的文字、拼音、念到这句时画面怎么演，以及画面本身，`g` 写年级（如 `三年级下`）。然后运行 `python3 dev/voice/build.py shi` 重录语音包（只录新的），看一眼它报出来的多音字和句尾声调。
古诗小剧场的语音都在一个包 `voice-shi.bin|json` 里（一到四年级 64 首的介绍、小故事、每句的大白话和朗诵），首页的读题语音包下载完接着下载，存进离线缓存后断网也能念任何一个年级（见「放到平板上」）。录音是按年级分开录的（`build.py shi 3` 只重录三年级，其余年级用 `dev/voice/cache/shi-parts/` 里录好的），最后合成一个包。

## 造物（`zaowu/`）

一个从混沌开始的小世界，全屏横竖屏都能玩。所有画面和音乐由代码实时生成，没有图片和音乐文件。

- **开场**：点一下混沌之蛋，旁白开始讲；再点三下，天地分开、群山升起
- **种树**：点草地种一棵树，桃、松、枫、柳、银杏轮流来，每种树有自己的乐器（古筝、钟、木琴、笛子、八音盒）
- **召云**：点天空召来一朵云，雨落下的地方开花；白天雨停会出彩虹
- **造生灵**：画一个首尾相连的形状，它就活过来，有名字、会说话、会跳、会睡觉；抓起来甩出去会转晕
- **动作圈**：点小生灵弹出五个按钮：唱歌（用「啦啦啦」唱一首老歌：小星星、两只老虎、欢乐颂、玛丽有只小羊羔）、吃果子、变色（顺带学颜色词）、翻跟头、说话
- **喂食**：点树会摇晃、掉果子，小生灵跑过去吃，吃三次会长大
- **小游戏栏**（右下角，竖屏在底部）：
  - **认一认**：点画面里任何东西（太阳、山、松树、萤火虫、樱桃……共 29 个词），弹出带拼音的词卡，中文、英文各读一遍，再读一句例句；认识过的词收进发现册的「词语」页，可以反复点着听
  - **找一找**：旁白问「松树在哪里？」并读出英文 pine tree，孩子在画面里找到点一下；只出现画面里真有的东西，也会问「红色的小伙伴在哪里？」；点错会亮出点到的词卡，连错两次给提示
  - **说一说**：五种日常句型（请你吃… / 请你做… / 我喜欢… / 我想要… / 打招呼），选一个词就听到整句中英文，然后点麦克风说给小伙伴听——它会用尖尖的声音学一遍，再照着做（吃樱桃、跳舞、变成蓝色、下雨、看星星、说晚安睡觉……）。录音只在页面里播放一次就丢掉；没有麦克风就点「我说好了」
  - **画一画**：选太阳、云、花、房子、帽子、小鸟、星星、小伙伴或随便画，用十支蜡笔画（点蜡笔会读出颜色的中英文），画好后程序看形状说「哇，圆圆的太阳！」「红色的，真好看！」，画就飞进世界里活过来：太阳挂上天，云会飘、点它下雨，花种在草地上随风摆，帽子戴到小伙伴头上
- **跟我唱**：有三个醒着的小生灵时小游戏栏里的 🎼 亮起，它们唱一串音，孩子按顺序点回去，2 个音加到 5 个音；点错只会重听一遍
- **晚上**：拖太阳到右边天就黑了，小生灵睡觉，萤火虫可以点来抓；八音盒放一首摇篮曲
- **发现册**：25 张贴纸 + 「词语」页，灰色的点一下会用语音提示怎么玩出来
- **中 / EN**：左上角一键切换，旁白、小生灵、按钮、发现册全部跟着换
- **透视**：给大人看的，把物理、递归、鸟群算法和声音波形画在画面上

### 语音

全站（首页闯关游戏约 700 句，找规律的讲解约 180 句，古诗小剧场约 500 段，造物约 2700 条）的每一句话都在构建时预先录好，压成语音包（MP3 拼接 + JSON 索引）随页面发布：
用的是微软的神经网络语音（[edge-tts](https://github.com/rany2/edge-tts)），中文旁白晓晓、小生灵晓伊和云夏，英文旁白 Ava、小生灵 Ana 和 Emma。

- **语速**：旁白约每秒 3.5 个音节、英文约每分钟 150 词，按六岁孩子听得清来定。
- **多音字**：先用 jieba + pypinyin + 手工核对的多音字表定下每个字该读什么；再把这个字换成各个读音的同音字重录几遍，
  比较原句和哪一遍最像，查出语音服务实际读成了什么；读错的（比如「一整行」读成 xíng、「宫商角徵羽」的「角」读成 jiǎo）
  就把同音字送给语音服务，屏幕上照旧显示原文。
- **中英文连读**：「苹果 → apple → 苹果脆脆的，甜甜的」这样总是连着说的几句录成一整段，每种语言用母语音色，停顿按真人节奏，
  不再三段音频各自起停。

语音包没下载完或句子不在包里时，退回设备自带的语音合成。录制、打包、核对的工具和说明在 [`dev/voice/`](dev/voice/README.md)。

家长设置里关掉「语音读题」或音效 / 背景音乐，进造物也会跟着关；造物里也有自己的「声音」「语音」开关。

### 修改造物

源码在 `zaowu/dev/`：改 `dev/src/` 里的文件后运行 `python3 zaowu/dev/build.py` 重新生成 `zaowu/index.html`。
改了台词运行 `python3 dev/voice/build.py zaowu` 重录语音包（见 `dev/voice/README.md`）；不重录的话，新句子会用系统语音读。

## 彩虹钢琴（`piano/`）

一架会发光的 3D 三角钢琴，给六岁左右的孩子做音乐启蒙，平板横竖屏都能弹。钢琴、舞台和所有特效都由代码实时生成（Three.js），没有模型文件。

- **七个音七种颜色**：do re mi fa sol la si 对应彩虹的赤橙黄绿青蓝紫，琴键上贴着同色的小圆贴，乐谱、提示、特效全部用同一套颜色，不识谱也能「看颜色弹」
- **开场**：一架盖着的钢琴站在彩虹舞台上，点一下，琴盖撑起、琴键盖翻开、镜头飞到琴凳上
- **两种视角**：「看钢琴」可以用手指转、捏合缩放，看琴弦、制音器、踏板；「展开键盘」坐到琴前，琴键按孩子手指的宽度放大（平板横屏一屏约 16 个白键，竖屏 11 个，手机 7 个），上方的小键盘导航条拖一下就到别的音区，八个音区用鲸鱼、大象 … 小蜜蜂标出低和高；家长设置里可以改成「全部 88 键」
- **声音看得见**：按下去的键在自己的颜色里发亮，升起一道光（按多久光就多长——看得见时值），飘出一个音符精灵（低音又大又慢，高音又小又快——看得见音高），弹出唱名；手指在琴键上滑过一串，头顶会出现一道彩虹。打开盖子能看到对应的制音器抬起
- **自己弹**：四种乐器（钢琴、八音盒、木琴、游戏机），踏板，白天 / 夜晚，九种琴身颜色；能录下自己弹的，再让钢琴自己弹给你听
- **跟我弹**：13 首公有领域的儿歌（彩虹音阶、小星星、小蜜蜂、玛丽有只小羊羔、两只老虎、欢乐颂、新年好、伦敦桥、粉刷匠、铃儿响叮当、生日快乐、圣诞快乐、送别），按难度 1–3 星。下一个要弹的键会发光，上方悬着一颗同色的糖果球和箭头；顶部是这一句的彩色乐谱和歌词，一句一句地学。不判错、不计时，弹错只会轻轻提示「找一找红色的那个键」。孩子每按对一个音，钢琴就在低音区配上和弦（可关），一个手指弹出来也像完整的曲子；弹完放烟花，再把整首按原速弹一遍，让孩子听到「我刚才弹的就是这首歌」
- **听我弹**：灯光暗下来，钢琴自己演奏，镜头像拍音乐会一样在六个机位之间缓缓移动；除了上面 13 首，还有致爱丽丝、小步舞曲、卡农
- **学小鸟**：小鸟先唱两个音（只用 do mi sol），孩子在琴上学一遍；连对两次加一个音，一直到 5 个音、整个八度。练的是音高记忆和听音模唱
- **语音**：所有旁白和站里其它游戏一样用 edge-tts（微软晓晓）预录成 `voice-zh.bin`，「弹」一律校正为 tán；家长设置里的声音 / 语音开关与首页同步
- **音色**：钢琴是 Salamander Grand Piano 的采样（Alexander Holm，CC BY 3.0），每小三度一个音，按琴键位置左右声像、加一点音乐厅混响和限幅（孩子常常十个手指一起按）；另外三种乐器实时合成

源码在 `piano/dev/`，改完运行 `node piano/dev/build.mjs` 生成 `piano/index.html` 和 `piano/app.js`（见 [`piano/dev/README.md`](piano/dev/README.md)）。改了台词运行 `python3 dev/voice/build.py piano` 重录语音包。钢琴用 ES 模块和 WebGL 2，需要 iOS 15 以上，要通过网址打开（不能直接打开本地文件）。

## 动物消消乐（`xiaoxiao/`）

开心消消乐那样的三消闯关，给六岁、玩过一些游戏的孩子。按平板横着拿来做（decli：先只照顾平板横屏），地图上十关一条路走下去，每关一到三颗星，过关拆一个盲盒。

- **小动物**：小猪、熊猫、河马、长颈鹿、鹦鹉、小青蛙，第 8 关起六种都上；小企鹅不能消，是要送回家的。头像是 decli 画的一套 70 个软糖质感的动物（`xiaoxiao/dev/art/`，切好打包成 `xiaoxiao/heads.webp`），棋盘上用其中 7 个，其余的在盲盒里
- **玩法**：手指按住一只往旁边拨，三只一样的连成一排就消掉。四只一排变出条纹小动物（消一整行或一整列），摆成 L 形、T 形变出炸弹，五只一排变出彩虹球（和谁换就把同样的全消掉）；两个特别的换在一起威力更大（彩虹球 + 彩虹球清空全场）
- **障碍**：冰块（一层 / 两层）、礼物盒（一层 / 两层，在旁边消才拆得开）、泡泡（里面的小动物拨不动）、小企鹅（把它下面的消掉，它就往下走，走到底就回家）
- **十关**：每关只多一样新东西，第一次见到时旁白讲一遍怎么玩。第 1 关就要在 18 步里收集 18 只小猪和 18 只熊猫，不是随便点点就过。
  步数和星星分数是用模拟器定的（`xiaoxiao/dev/sim.js`）：两个机器人各玩几百局，「随便找一个能消的」大约赢 14%–73%，「每步挑最有用的」赢 87%–100%，孩子落在两者之间
- **好看好听**：消除时的爆裂、条纹的光束、炸弹的冲击波、彩虹球的闪电、小动物飞向目标的弧线；一步里连消越多，喊得越响：Great! → Excellent! → **Unbelievable!**（decli 请人录的，`xiaoxiao/sound/`），过关时剩下的步数变成条纹小动物，Bonus time! 一起炸开
- **背景音乐**：decli 请人配的两首欢快的曲子（`xiaoxiao/sound/bg1.mp3`、`bg2.mp3`）一首接一首地放，地图、关卡、卡片、拆盲盒时都不停，只有暂停和做数学题时停下；旁白说话时音乐稍微小一点
- **过关拆盲盒**：每过一关掉下来一个盲盒，点三下打开（每点一下盒子跳一下、缝里的光更亮），蹦出一个动物小伙伴，旁白说出它的名字。星星越多盒子越好（一星粉色、二星紫色、三星金色），抽到**稀有款**（金光）和**隐藏款**（小龙、独角兽，彩虹光）的机会越大；还没有的小伙伴总是先出，重复的记成 ×2、×3。地图右上角 🎁 打开**动物收集册**：70 个格子，有了的是彩色头像（点一下说名字），没有的是一个影子加问号，可以猜猜是谁；棋盘上的 7 个一开始就在
- **卡住会提示**：7 秒不动，能消的那一步轻轻晃，一只小手示范怎么拨（第一局开始 1.5 秒就示范，拨过一次后恢复 7 秒）；没有能消的了会自动洗牌
- **不在棋盘上弹字**：孩子还不识字，游戏里不弹文字框。变出特别的小动物时，它周围亮起金色光圈，并画出它能干什么（条纹两边的箭头、炸弹的炸开范围、彩虹球的彩虹圈），同时喊一声 Great! / Excellent!；每种前三次还有一只小手示范它真能走的那一步，第一次再配一句很短的旁白。手一碰棋盘提示就退开。关前卡片和结果卡片也只用图和数字（步数、目标、🏆 最高分、✏️ +5 步），要说明的话都由旁白念
- **随时回小画本**：地图左上角、游戏里暂停键旁边、数学题页左上角都有 🏠，一点就回到思维小画本首页

### 防沉迷 + 玩中学：一页数学题

- 每玩一局（走出第一步就算），想**再玩一次**或**进下一关**，都要先做完一页 **20 道**加减法，全部做对才能开始。退出去换一关也一样
- 题目每页现出：范围 **20 / 50 / 100 以内**，**两个 / 三个 / 四个**数连着加减，**加减混合 / 只有加法 / 只有减法**；中间每一步都不出现负数，也不超过范围
- 用屏幕上的大数字键盘答，答错轻轻一抖说「再想一想」；连错三次把答案用灰字写出来，照着写一遍就过，不会卡住
- 平板上一页排成四列；四个数连着算时，自动改成三列，算式不会被截掉
- 做到一半点 🏠 回小画本也可以，但这一页不算做完，下次进来还是先做题
- 步数用完没过关时，可以做 **5 道题换 5 步**，一局一次
- **家长专区**（地图右上角 ⚙️，或数学题页的 🔒）：先答一道「七乘以八等于多少」这样的汉字乘法题才进得去。在这里设范围、几个数、题型（下一页起生效，在数学题页里改会马上换一页），看今天做了几页、第一次就做对的比例、每页用了多久，也能临时免做一页、解锁全部关卡或清空进度
- 进度、星星、收集册和做题记录存在这台设备的浏览器里（`logicc.xiaoxiao.v1`）

## 魔方世界（`mofang/`）

练三维空间感的 3D 小世界，给平板做的，横竖屏都能玩。六个漂浮小岛围成一圈，手指一拨换一个岛，点岛进去；每关三题，按错几次给一到三颗星。积木、小动物、魔方、小岛都是代码实时生成的（Three.js），没有模型文件。

- **👀 小熊看积木**（5 关）：小熊、小兔、小猫、小青蛙、小鸟站在积木堆的前、右、左、后、上面，选它看到的平面图；答完镜头飞到它的眼睛那里，积木一点点「压扁」成和卡片一样的图。后面反过来：给一张图，点是哪只小动物看到的；最后一关先不许转，想好再看
- **🔢 数积木**（5 关）：数一共几块，后面藏在下面和后面的也要算；数完积木飞散开，一块一块报数。还有一关是「还要几块才能拼成一个大方块」
- **🧱 钻墙洞**（5 关）：墙上有个洞，用转圈 / 左右转 / 前后翻三个按钮（或手指拨）把积木转成洞的样子，按 🚀 冲过去，墙炸开；不对就「咚」地弹回来。墙上的影子告诉你现在从后面看是什么样，最后一关影子不给
- **📦 折纸盒**（5 关）：六个正方形的展开图少一块，点虚线框补上，纸就自己折起来，折成了是个盒子，叠在一起了会闪红再摊开；之后判断「能不能折成盒子」，最后问「折好以后哪个颜色在星星的对面」
- **🎲 转魔方**（6 关 + 自由玩）：先看着魔方被打乱一两下，再用手指按住一层往旁边推把它转回去；二阶 → 三阶，一步 → 三步。卡住了点 💡 有箭头指着该转哪一层。自由玩可以选 2×2 / 3×3、打乱、退回、看它自己复原，还能把颜色换成图案贴纸（小心心、笑脸、太阳…）
- **🏰 搭城堡**（5 关 + 自由玩）：先在亮亮的格子上放积木；再照着小窗口里的样子搭（小窗口跟着你的视角一起转）；再搭转了方向的（看小旗子找前面）；最后只给小熊从前面看和小鸟从上面看两张图来搭。自由玩有十一种颜色和屋顶、窗户、门、小树、旗子，点 🏰 送一座城堡，搭的东西会自己存下
- **不弹字**：游戏里所有话都由旁白念（晓晓），答对时喊 Good! → Great! → Amazing! → **Unbelievable!**（Ana），配彩带和星光；十几秒没动作会重读题目或给提示
- **随时回小画本**：左上角 🏠，在小岛里点一下回到小岛圈，在小岛圈再点回到思维小画本
- 进度和星星存在这台设备的浏览器里（`logicc.mofang.v1`）；家长设置 ⚙️ 在小岛圈右上角，要先答一道乘法题

## 放到平板上

1. 打开 <https://decli.github.io/logicc>
2. iPad Safari：分享 → 添加到主屏幕；Android Chrome：菜单 → 添加到主屏幕
3. 用主屏幕图标打开一次，连着网等它下载完（家长设置 ⚙️ 里「离线使用」显示 ✅ 就好了，约 32 MB），之后断网也能玩，古诗一到四年级都能念

离线靠 `sw.js`（service worker）：
- 第一次打开时，首页、图标、读题语音包 `voice-zh`、找规律的讲解 `voice-gl` 和古诗语音包 `voice-shi` 边下载边存进浏览器缓存，只下载一遍
- 以后每次打开都先用缓存，有网时顺手检查新版本：首页最多等网络 4 秒，等不到就用缓存里的
- 语音包的索引 json 里带着 bin 的指纹，页面按 `voice-xx.bin?h=指纹` 去取；新版本的 bin 整个下载完才会换上，下载到一半断网，用的还是旧的那一对，不会出现索引和声音对不上
- 「造物」「彩虹钢琴」「动物消消乐」「魔方世界」不预先下载（加起来四十多 MB），打开过一次就存下，之后断网也能玩
- iPad 上请从主屏幕图标打开：Safari 浏览器里打开的网页，太久不用会被系统清掉缓存，主屏幕上的不会

古诗小剧场第一次进「跟我念」时会弹出「使用麦克风」，请家长点允许（不允许也能玩，孩子念完点「✋ 我念完了」）。
声音只在这台设备上判断有没有开口，不上传；「我来背」的录音存在这台设备的浏览器里，设置里「清空」会一起删掉。

### 换个网址（Cloudflare）

github.io 打不开时，同一个仓库在 Cloudflare 上还部署了一份（Workers 的静态网站，绑在自己的子域名上，部署的是这个仓库的 `main`，推送后一分钟左右自动更新）。

1. Cloudflare 后台 → Workers & Pages → 创建 → 导入 Git 仓库，选这个仓库，生产分支 `main`；不需要构建，整个仓库根目录就是网站
   （也可以建成 Pages 项目：框架选「无」，构建命令 `exit 0`，输出目录 `/`）。
   根目录的 `wrangler.jsonc` 写明了 Worker 名 `logicc` 和「整个目录都是静态文件」：PR 分支的预览构建（`wrangler versions upload`）
   不会像正式构建那样自动生成配置，没有这个文件就会失败。`.assetsignore` 列出不上传的东西（`.git` 等）
2. 想用自己的域名：在这个项目的「域和路由」（Pages 叫「自定义域」）里加一个子域名，比如 `play.你的域名`，DNS 记录和证书 Cloudflare 会自动加
3. 根目录的 `_headers` 只有 Cloudflare 读：所有文件带 `X-Robots-Tag: noindex`，首页和 `sw.js` 每次检查新版本，语音包长缓存；
   `robots.txt` 只放 Google、Bing 进来（它们要读到 noindex 才不收录），其他爬虫、AI 训练爬虫一律不让抓。和主站不互相链接，就不会影响主站的搜索收录
4. Cloudflare 会把 `/index.html` 跳转到 `/`，所以 `sw.js` 不缓存跟着跳转拿到的页面（浏览器不认这种响应，会打不开），`manifest` 的起始页也是 `./`

注意：进度、星星和「我来背」的录音存在浏览器里，按网址分开存，换了网址要从头开始；离线缓存也要在新网址上重新下载一次。

也可以直接把 `index.html` 传到平板上离线打开（这样打开读不到语音包，读题会改用平板自带的语音）。

## 开发

闯关游戏没有构建步骤，所有代码都在 `index.html` 里（HTML + CSS + 原生 JS，无框架、无外部请求，只从同目录读语音包 `voice-zh.*`、`voice-gl.*` 和 `voice-shi.*`；离线缓存是 `sw.js`）。改了读题的句子后运行 `python3 dev/voice/build.py root` 重录语音包（只录新句子）；改了找规律的题目或讲解运行 `python3 dev/voice/build.py gl`；改了古诗小剧场的诗或台词运行 `python3 dev/voice/build.py shi`。造物见上面「修改造物」。
本地预览：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```
