# 思维小画本（logicc）

给幼儿园大班小朋友的思维训练小游戏，把纸质练习册上的题目改成了平板上能玩的游戏。
单文件 HTML，零依赖、可离线，加到主屏幕就是一个 App。

在线玩：<https://decli.github.io/logicc>

## 八个游戏

| 游戏 | 原型练习纸 | 练什么 | 关卡 |
| --- | --- | --- | --- |
| 找数字 | 舒尔特方格 | 视觉搜索、专注力 | 2×2 → 5×5 |
| 数点点 | 多米诺点数 | 目测点数、凑十 | 5 以内 → 10 以内 |
| 凑数字 | 10 以内数的分解与组成 | 数的组成 | 5 以内 → 10 以内 |
| 找一样 | 数字连连看 | 视觉辨别、细节对比 | 2 位数 → 6 位乱序数字 |
| 照镜子 | 对称图形 | 空间镜像 | 3×3 → 5×5 |
| 连点成画 | 螺旋图记数字 | 顺序追踪、数序 | 7 个点 → 20 个点 |
| 水果连连看 | — | 视觉搜索、路径规划 | 自由配对 → 两折连线规则 |
| 走迷宫 | — | 路径规划、手眼协调 | 4×4 → 8×8 |

## 给孩子的设计取舍

- **一组三关**，1–2 分钟一轮，顶部三个圆点让孩子看得见"快结束了"；三关给一张贴纸。
- **不判错**：点错只是轻轻抖一下，没有红叉、不扣分、没有倒计时，可以一直试。
- **全程语音**：不识字也能玩。每题自动朗读，右上角 🔊 可随时重读一遍。
- **自适应难度**：连续三关零失误自动升级，一关错四次自动降级；家长可在 ⚙️ 里锁定并手动调。
- **卡住会提示**：7–20 秒没动作，正确选项自动发光并重读题目；迷宫可以"看一眼路"。
- **声音**：Web Audio 实时合成的背景音乐与音效，无音频文件；朗读时音乐自动压低。

## 家长设置（右上角 ⚙️）

音效 / 语音读题 / 背景音乐 / 自动调整难度开关，以及每个游戏的关卡手动加减。

## 放到平板上

1. 打开 <https://decli.github.io/logicc>
2. iPad Safari：分享 → 添加到主屏幕；Android Chrome：菜单 → 添加到主屏幕
3. 之后全屏图标启动，断网也能玩

也可以直接把 `index.html` 传到平板上离线打开。

## 开发

没有构建步骤，所有代码都在 `index.html` 里（HTML + CSS + 原生 JS，无框架、无外部请求）。
本地预览：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 已知取舍

星星和贴纸只在本次打开期间保留，刷新后归零——这是刻意的，避免孩子为了攒数字反复刷。
如果需要跨天累计和家长周报，可以接 `localStorage`。
